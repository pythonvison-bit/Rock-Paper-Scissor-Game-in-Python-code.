# Rock Paper Scissors Game

A simple Rock Paper Scissors game built with Python.

The computer randomly chooses rock, paper, or scissor.

The player competes against the computer.

## How to Play

Run the Python program.

Enter `rock`, `paper`, or `scissor`.

The game will tell you whether you win, lose, or draw.

## Technologies Used

Python

Random module

## About

This is a beginner-friendly project.

It helps practice user input, conditional statements, and the random module.
